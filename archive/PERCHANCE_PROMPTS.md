# BIOARMOR - Perchance Prompts (Honest-Framing Edition)

> **HONEST FRAMING — read before generating.**
> Algae is a **supplemental O₂ source + CO₂ scrubber / redundancy layer**, NOT primary life support.
> Primary O₂ comes from compressed-oxygen and chemical-oxygen reserves. When depicting the
> algae layer, show it as a living CO₂-processing / backup-O₂ system — NOT as the astronaut's
> main breathing source. Keep the green glow as an aesthetic + health-indicator feature, but
> never label it as the sole or primary O₂ supply. Mirror the numbers in `docs/RESEARCH_BRIEF_2026.md`:
> algae covers ~20–33% of resting O₂ need and "buys time, not replaces the system."

## Perchance Tips

### General
1. Generate 5-10 times per prompt
2. Negative prompt: blurry, low quality, cartoon, anime, deformed, extra limbs, opaque visor, bulky, oversized
3. Style keywords: concept art, 8k, ultra detailed, cinematic, NASA
4. Aspect ratio: 9:16 for full body, 16:9 for split screen, 1:1 for close-ups
5. **Honesty guard:** never depict algae as the sole/primary O2 source; always pair it with the primary compressed/chemical O2 system and label it supplemental/CO2-scrub.

### V1 Key Visuals
6. V1 suit = sleek, form-fitting, white Kevlar with hexagonal chain mail texture woven into fabric
7. V1 green tint = living algae CO2-scrub / supplemental-O2 layer (redundancy), not primary air
8. V1 tendon cables = thin dark lines running from torso motor housings to joint pulleys
9. V1 LEDs = tiny bright dots providing light to algae
10. V1 should look like high-end compression wear with subtle protective texture

### V2 Key Visuals
11. V2 = hexagonal white ceramic tiles on dark CNT mesh framework
12. V2 tiles = snap onto mesh, modular, removable
13. V2 green tint = algae supplemental O2 / CO2 scrub visible between tiles
14. V2 algae pods = small transparent tanks with green culture on chest/back (labeled backup O2 / CO2 scrub)
15. V2 CNT mesh = dark woven fabric skeleton visible between tiles

### Common Issues
16. If suit looks too bulky: emphasize form-fitting compression wear aesthetic
17. If green is too dominant: keep algae as a subtle tint/health indicator, not a glowing primary system
18. If chain mail not visible in V1: add hexagonal scale pattern woven into fabric
19. If tiles not clear in V2: add white hexagonal ceramic tiles snapping onto dark mesh
20. CNT mesh should appear as dark woven fabric; LEDs as tiny bright dots
