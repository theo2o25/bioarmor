## Perchance Tips

### General
1. Generate 5-10 times per prompt
2. Negative prompt: blurry, low quality, cartoon, anime, deformed, extra limbs, opaque visor, bulky, oversized
3. Style keywords: concept art, 8k, ultra detailed, cinematic, NASA
4. Aspect ratio: 9:16 for full body, 16:9 for split screen, 1:1 for close-ups

### V1 Key Visuals
5. V1 suit = sleek, form-fitting, white Kevlar with hexagonal chain mail texture woven into fabric
6. V1 green glow = bioluminescent emerald glow from algae beneath chain mail surface
7. V1 tendon cables = thin dark lines running from torso motor housings to joint pulleys
8. V1 LEDs = tiny bright dots providing light to algae
9. V1 should look like high-end compression wear with subtle protective texture

### V2 Key Visuals
10. V2 = hexagonal white ceramic tiles on dark CNT mesh framework
11. V2 tiles = snap onto mesh, modular, removable
12. V2 green glow = visible between tiles from algae layer beneath
13. V2 algae pods = small transparent tanks with green culture on chest/back
14. V2 CNT mesh = dark woven fabric skeleton visible between tiles

### Common Issues
15. If suit looks too bulky: emphasize form-fitting compression wear aesthetic
16. If green glow is weak: add bioluminescent emerald glow from within
17. If chain mail not visible in V1: add hexagonal scale pattern woven into fabric
18. If tiles not clear in V2: add white hexagonal ceramic tiles snapping onto dark mesh
19. CNT mesh should appear as dark woven fabric
20. LEDs should appear as tiny bright dots
