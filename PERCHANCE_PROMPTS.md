## Perchance Tips

1. Generate 5-10 times per prompt
2. Negative prompt: "blurry, low quality, cartoon, anime, deformed, extra limbs, opaque visor, bulky, oversized"
3. Style keywords: "concept art, 8k, ultra detailed, cinematic, NASA"
4. Aspect ratio: 9:16 for full body, 16:9 for split screen, 1:1 for close-ups
5. Key visual distinction: Daily suit = sleek, form-fitting, white Kevlar with green glow from LEDs and tendon cables and subtle liquid cooling micro-tubes. ExoArmor = hexagonal tiles on dark CNT mesh, modular, armored with snap-on algae pods, specialized gloves and boots, HUD display and dust shield electrodes on helmet.
6. If tiles look too bulky: emphasize "slim hexagonal tiles" and "form-fitting armor"
7. If green glow is weak: add "bioluminescent emerald glow from within"
8. CNT mesh should appear as dark woven fabric underneath tiles
9. LEDs should appear as tiny bright dots providing light to algae
10. Tendon cables should appear as thin dark lines running from torso motor housings to joint pulleys
11. Algae pods should appear as small transparent tanks with green culture inside
12. Gloves should show Kevlar fabric with ceramic particle coating and silicone grip pads
13. Boots should show Vibram sole with piezoelectric insole visible at edge
14. HUD should show O2 levels, battery status, and temperature as faint green overlay on visor
15. Dust shield electrodes should appear as subtle transparent grid pattern on helmet visor
